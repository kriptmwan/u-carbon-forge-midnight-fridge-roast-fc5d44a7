A make.fun competition entry: one line roasting a smart fridge that refuses to open after midnight.

## Entry

> Midnight snack run, denied: my fridge locked the door and the ice cream pressed charges.

88 characters. A midnight snack run gets denied at the door — the fridge locks itself, and the ice cream, of all things, has pressed charges against the hungry human.

## How it works

`main.ts` validates the roast (1–200 characters, not only whitespace, counted in code points) and writes it to `/output/entry.txt`.

Run with Node 22:

```sh
node main.ts
```
